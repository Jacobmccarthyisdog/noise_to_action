# From Noise to Action Web

This is the Vercel-ready Next.js dashboard for the portfolio tracker.

The web app reads one static data contract:

```text
web/public/data/dashboard.json
```

That file is generated by the existing Python analytics layer:

```bash
python jobs/export_dashboard_data.py
```

## Local Development

From the repository root:

```bash
python -m pip install -r requirements.txt
python jobs/generate_daily_insight.py --force
python jobs/export_dashboard_data.py
```

Then run the web app:

```bash
cd web
npm install
npm run dev
```

Open `http://localhost:3000`.

## Data Refresh

`.github/workflows/generate_daily_insight.yml` now runs every 6 hours. It:

1. installs the Python dashboard dependencies
2. regenerates `data/daily_insight.json`
3. exports `web/public/data/dashboard.json`
4. commits changed dashboard artifacts back to the repo

When connected to Vercel, each committed data refresh can trigger a fresh deployment.

## Vercel Setup

In Vercel:

1. import this GitHub repository
2. set the project root directory to `web`
3. use framework preset `Next.js`
4. keep build command as `npm run build`
5. keep output directory as the Next.js default
6. add `OPENAI_API_KEY` as a GitHub Actions secret, not a Vercel secret, because data generation happens in GitHub Actions

The deployed app will fetch `/data/dashboard.json` at runtime.
